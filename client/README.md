# 🛍️ Vintage Factory — Frontend Web Client

This is the Next.js 16 frontend for the **Vintage Factory** e-commerce platform.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
